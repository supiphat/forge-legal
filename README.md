# forge-legal

- Privacy policy: `https://supiphat.github.io/forge-legal/privacy.html`
- Terms of service: `https://supiphat.github.io/forge-legal/terms.html`

Source of truth lives in the (private) Forge repo at `docs/PRIVACY.md` and `docs/TERMS.md`. Updates here are mirrored from there.
